# Deploy this site tonight

## Fastest: Netlify

1. Edit `index.html` and `styles.css`.
2. Put your images in `assets/`.
3. Replace the placeholder image blocks with:
   `<img src="assets/your-image.jpg" alt="Description">`
4. Add your CV as `assets/cv.pdf`.
5. Zip or use the folder as-is.
6. In Netlify, create a new site and use the manual drag-and-drop deploy option.
7. Once live, open **Domain management → Production domains** and add a domain you already own.
8. Netlify will show the DNS records you need to add at your domain registrar.

## GitHub Pages alternative

1. Create a repository.
2. Upload these files.
3. Open **Settings → Pages**.
4. Publish from the `main` branch.
5. Add your custom domain under **Custom domain**.
6. Update DNS at your registrar using GitHub's instructions.

## Before launch

- Replace the email address.
- Replace LinkedIn/GitHub `#` links.
- Add your CV.
- Add 3–5 strong images.
- Rewrite the placeholder descriptions.
- Update the `<title>` and description if needed.
